    Google Cloud Console: maak een API-sleutel en schakel Routes API en Places API (New) in. Nodig voor Google-routes en Google-restaurants; zonder sleutel gebruikt Wegwijs OpenStreetMap.

    tripadvisor.com/developers: Content API, gratis tot 5.000 oproepen per maand. Zet geen referrer-beperking op de sleutel.

    Start eerst een navigatie; de demo stuurt dan nep-posities langs de route naar de bril, handig om alles te bekijken zonder te wandelen.
